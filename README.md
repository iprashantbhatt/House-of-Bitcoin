## 📖 Overview

**House of Bitcoin** is a real-time dashboard built for anyone who wants a single, clean view into everything Bitcoin — live price action, the halving countdown, market sentiment, on-chain data, and the top coins in the market — wrapped in a slick, themeable interface.

🔗 **Live App:** [houseofbitcoin.app](https://www.houseofbitcoin.app/)
🌐 **More projects:** [prashantbhatt.net](https://prashantbhatt.net)

## ✨ Features

- 📈 **Live BTC Price** — real-time price tracking
- ⏳ **Halving Countdown** — live countdown to the next Bitcoin halving
- 😱 **Fear & Greed Index** — current market sentiment at a glance
- ⛓️ **On-Chain Metrics** — key Bitcoin network data
- 🏆 **Top 100 Coins** — broader market overview beyond just BTC

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/iprashantbhatt/House-of-Bitcoin.git
cd House-of-Bitcoin

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

### Running Locally

```bash
# Start the backend
cd backend
npm start

# In a separate terminal, start the frontend
cd frontend
npm start
```

> ⚠️ You may need to configure API keys (e.g. for price/on-chain/news data sources) in a `.env` file in `backend/`. See the backend source for required variables.
